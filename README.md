# 🎙️ AI-Style Debate Generator

A modern, fully responsive web application that generates arguments **FOR** a topic, arguments **AGAINST** it, and provides a **neutral conclusion**. It features a beautifully designed dark/cyberpunk neon user interface with smooth animations.

## ✨ Features
- **Dynamic Argument Generation:** Provides tailored viewpoints for specific popular topics (like Social Media, AI Art, School Uniforms) and utilizes a dynamic fallback system to handle *any* custom topic gracefully.
- **Modern Responsive Design:** A sleek, mobile-friendly cyberpunk theme with glowing visual indicators for different perspectives.
- **Instant Validation:** Built-in error handling for empty inputs to ensure a smooth user experience.
- **Zero External Dependencies:** Built using pure vanilla web languages without needing heavy frameworks or databases.

## 🛠️ Built With
- **HTML5** - Semantic structure and layout skeleton.
- **CSS3** - Custom dark mode, grid layouts, neon borders, and transitions.
- **JavaScript (ES6)** - App state logic, user input validation, dynamic DOM injection, and data management.
